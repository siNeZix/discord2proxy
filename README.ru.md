# discord2proxy

> **🇬🇧 [Read in English → README.md](README.md)**

Инструмент для разворачивания SOCKS5-прокси для **Discord** на **Windows**.
Принудительно направляет сетевой трафик Discord через локальный SOCKS5-прокси
(v2ray / nekobox), встраивая небольшую DLL-загрузчик и конфиг `proxy.txt` в
каталог приложения Discord.

Без системного прокси, без VPN, без прав администратора — маршрутизируется
только Discord.

---

## Как это работает

1. **Обнаружение прокси** — TCP-подключение + SOCKS5-рукопожатие на
   `127.0.0.1:2080` (nekobox), затем `127.0.0.1:1080` (v2ray); выбирается первый
   живой адрес.
2. **Поиск Discord** — через реестр Windows (`HKCU\...\Uninstall`) и известные
   пути в `%LocalAppData%`, с приоритетом каналов:
   `stable > ptb > canary > development`.
3. **Развёртывание** — записывает `proxy.txt` (`SOCKS5_PROXY_ADDRESS` /
   `SOCKS5_PROXY_PORT`) и копирует встроенные DLL (`DWrite.dll`,
   `force-proxy.dll`) в каталог Discord `app-x.x.x`.
4. **Проверка** — подтверждает, что файлы скопированы корректно. Перезапустите
   Discord, чтобы применить.
5. **Удаление** — убирает `proxy.txt` и DLL из каталога Discord.

Формат конфига, записываемого в `proxy.txt`:

```
SOCKS5_PROXY_ADDRESS=127.0.0.1
SOCKS5_PROXY_PORT=2080
```

## Компоненты

| Бинарник         | Описание                                                                 |
| ---------------- | ------------------------------------------------------------------------ |
| `d2p.exe`        | GUI (фреймворк Gio). Тёмная тема, русский интерфейс, карточки установки.  |
| `d2p-cli.exe`    | Консольный деплоер (на флагах).                                           |
| `d2p-setup.exe`  | Лёгкий загрузчик: скачивает актуальный GUI и устанавливает его.           |

### GUI (`d2p.exe`)

- Окно 420×320 с карточками статуса и кнопками установки / удаления.
- Предлагает установить себя в `%LocalAppData%\discord2proxy\`, создаёт ярлыки
  на Рабочем столе и в меню Пуск (через COM `IShellLinkW`) и запись удаления в
  HKCU — без запроса UAC.
- **Самообновление**: при запуске запрашивает последний релиз на GitHub,
  сравнивает с вшитой версией и показывает кнопку «Обновить vX.Y.Z», когда
  доступна более новая сборка. По клику атомарно заменяет работающий бинарник и
  перезапускается.

### CLI (`d2p-cli.exe`)

```
d2p-cli [флаги]
```

| Флаг             | По умолчанию | Описание                                                     |
| ---------------- | ------------ | ------------------------------------------------------------ |
| `-proxy-port`    | `0` (авто)   | Переопределить порт прокси (`0` = автоопределение 2080 / 1080). |
| `-proxy-host`    | `127.0.0.1`  | Переопределить хост прокси.                                  |
| `-discord-path`  | _(пусто)_    | Переопределить путь установки Discord.                       |
| `-channel`       | _(пусто)_    | Выбрать канал: `stable` \| `ptb` \| `canary` \| `development` (алиас `dev`). |
| `-dry-run`       | `false`      | Показать действия без выполнения.                           |
| `-force`         | `false`      | Развернуть, даже если Discord запущен / прокси недоступен.   |
| `-no-verify`     | `false`      | Пропустить проверку после развёртывания.                    |

### Setup (`d2p-setup.exe`)

Нативный Win32-загрузчик (не Gio), который скачивает актуальный `d2p.exe` по
HTTP (с индикатором прогресса), устанавливает его и запускает. Также
публикуется сжатый UPX-вариант (`d2p-setup-upx.exe`).

## Сборка

Требуется **Go 1.26+**, **только Windows**.

```sh
make          # собирает CLI, GUI и Setup в build/
make clean    # удаляет build/
```

Отдельные цели: `make build`, `make build-gui`, `make build-setup`,
`make build-setup-upx`.

Версия подставляется на этапе сборки из git-тега через:

```
-ldflags "-X discord-szx/internal/config.Version=<версия>"
```

---

## Релизы

Релизы управляются тегами. Пуш тега `vX.Y.Z` запускает release-workflow,
который собирает все бинарники на `windows-latest` и публикует GitHub Release с
вложениями `d2p-cli.exe`, `d2p.exe`, `d2p-setup.exe` и `d2p-setup-upx.exe`.

```sh
git tag v0.5.0
git push origin v0.5.0
```

## Структура проекта

```
internal/proxy/          Обнаружение SOCKS5 через рукопожатие
internal/update/         Самообновление через GitHub Releases (minio/selfupdate)
third_party/gioui.org/   Вендоренный, пропатченный Gio
```
